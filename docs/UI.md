# Web UI

Одна статическая страница без React/Vue/Angular и без сборщика (`static/index.html`, `static/app.js`, `static/styles.css`).

Покрывает весь сквозной сценарий:
- сводные показатели (число аукционов, лотов, продаж, выручка);
- создание аукциона и управление статусом (запустить / завершить / отменить);
- создание продавцов и покупателей, их списки;
- создание лота с выбором аукциона (в списке только PLANNED/ACTIVE) и продавца;
- список лотов со статусом; для лота AVAILABLE активного аукциона — инлайн-форма ставки (с просмотром истории ставок) и инлайн-форма продажи (покупатель + цена), создание продажи сразу закрывает лот;
- список продаж.

Запросы выполняются через `fetch` в тот же FastAPI backend (`/api/...`). Ошибки API (4xx с полем `detail`) отображаются пользователю в блоке сообщения внизу страницы.
