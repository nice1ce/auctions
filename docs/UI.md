# Web UI

Одна статическая страница без React/Vue/Angular и без сборщика (`static/index.html`, `static/app.js`, `static/styles.css`).

Покрывает весь сквозной сценарий:
- сводные показатели (число аукционов, лотов, продаж, выручка в рублях);
- создание аукциона и управление статусом (запустить / завершить / отменить);
- создание продавцов и покупателей, их списки в виде таблиц;
- создание лота с выбором аукциона (в списке только PLANNED/ACTIVE) и продавца;
- таблица лотов со статусом, стартовой ценой и обновляющейся текущей ценой (`current_price` из API); для лота AVAILABLE активного аукциона — инлайн-форма ставки (с просмотром истории ставок, минимальный шаг 100 ₽) и инлайн-форма продажи (покупатель + цена), создание продажи сразу закрывает лот;
- таблица продаж.

Запросы выполняются через `fetch` в тот же FastAPI backend (`/api/...`). Ошибки и успешные действия отображаются всплывающими уведомлениями (toast) в правом нижнем углу, а не статичным блоком на странице.
