# HTTP API

Service: `GET /health`, `GET /version`

Auctions: `GET/POST /api/auctions`, `GET/PATCH/DELETE /api/auctions/{id}`, `POST /api/auctions/{id}/start`, `POST /api/auctions/{id}/finish`

Sellers: `GET/POST /api/sellers`, `PATCH /api/sellers/{id}`

Buyers: `GET/POST /api/buyers`, `PATCH /api/buyers/{id}`

Lots: `GET /api/lots`, `GET/PATCH/DELETE /api/lots/{id}`, `POST /api/lots`, `GET/POST /api/lots/{id}/bids`, `POST /api/lots/{id}/sell`

Sales/reports: `GET /api/sales`, `GET /api/sales/{id}`, `GET /api/reports/revenue`

Swagger: `/docs`.
