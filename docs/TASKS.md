# План задач Lab 1

Backend:
- TASK-01: FastAPI + конфигурация
- TASK-02: модели + PostgreSQL + миграции
- TASK-03: CRUD аукционов
- TASK-04: продавцы/покупатели/лоты
- TASK-05: ставки и бизнес-правила
- TASK-06: продажи и отчет

UI / DevOps / Docs:
- TASK-07: HTML/CSS/JS
- TASK-08: тесты
- TASK-09: Makefile + локальный PostgreSQL
- TASK-10: документация + CI

Для каждой задачи: issue → `feature/...` → несколько осмысленных коммитов → `make verify` → PR → review → merge.

Для демонстрации Git-конфликта рекомендуется изменить одну строку README в двух ветках и затем разрешить конфликт через merge.
